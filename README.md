# 🍅 Мини-приложение «FRESCONTI» для мессенджера MAX

Каталог премиальных солений, соусов и маринадов бренда **FRESCONTI** — на основе сайта
производителя [zar-sol.ru](https://zar-sol.ru) (ООО «Царицынские соленья», г. Волжский)
и витрины бренда на [Wildberries](https://www.wildberries.ru/brands/310930370-fresconti).

Работает внутри мессенджера **MAX** через библиотеку **MAX Bridge** (`window.WebApp`).
Вне MAX подставляется мок, поэтому приложение можно открывать и дорабатывать в обычном браузере.

## Что умеет

- Каталог по категориям: соусы без сахара, антипасти в масле, соленья, острое, конфитюры, консервы
- Поиск по товарам, рейтинг и число отзывов с Wildberries (соц-доказательство)
- Карточка товара с описанием и кнопкой **«Купить на Wildberries»** (внешняя ссылка)
- **Избранное** с сохранением в `DeviceStorage` (переживает перезапуск)
- Раздел **«О бренде»**: история, производитель, контакты + **форма опт-заявки** (СТМ)
- Приветствие по имени из профиля MAX, шаринг в MAX, тактильные отклики, кнопка «Назад»
- Ввод номера телефона кнопкой **«Взять из MAX»** (`WebApp.requestContact()`)

## Цены (парсер Wildberries)

Цены на карточки подтягиваются из `prices.json`, который формирует парсер
`scripts/update_prices.py` — он одним запросом забирает витрину WB по бренду и сохраняет
актуальные цены (поле `sizes[].price`: `product` — текущая, `basic` — без скидки).

- запуск вручную: `python scripts/update_prices.py`
- автообновление: cron-задача Hermes (`update-fresconti-prices.sh`) запускает парсер и
  коммитит/пушит `prices.json` при изменении цен — GitHub Pages пересобирается сам.

Цены привязаны к региону доставки (Москва, `dest=-1257786`) и могут отличаться по региону —
точную цену клиент видит на карточке Wildberries.

## Быстрый старт (локальная проверка)

```bash
cd fresconti-max-miniapp
node server.js
# откройте http://localhost:3000
```

Без `BOT_TOKEN` заявки принимаются в демо-режиме (валидация отключена, в консоли — предупреждение).
С токеном:

```bash
# Linux/macOS
BOT_TOKEN=ваш_токен node server.js
# Windows (PowerShell)
$env:BOT_TOKEN="ваш_токен"; node server.js
```

## Публикация и подключение к MAX

1. **Задеплойте мини-приложение** на хостинг с HTTPS. Подойдут:
   [GitHub Pages](https://pages.github.com) (только статика — без приёма заявок),
   [VK Cloud (хостинг мини-приложений)](https://cloud.vk.com),
   [Render](https://render.com) (Blueprint `render.yaml` — статика + `/api/lead` в одном сервисе),
   [Yandex Cloud](https://cloud.yandex.ru).

2. **Подключитесь к платформе MAX для партнёров** ([dev.max.ru](https://dev.max.ru/docs)):
   - подходит юрлицу, ИП или самозанятому (резидент РФ);
   - создайте и верифицируйте профиль организации.

3. **Создайте чат-бота** на платформе — получите `BOT_TOKEN`.

4. **Привяжите мини-приложение**: панель управления ботом → **Расширенные настройки → Настроить** →
   вставьте URL мини-приложения (HTTPS) → выберите кнопку («Открыть») → **Сохранить**.

5. **Приём опт-заявок**: если статика и бэкенд на разных доменах, укажите абсолютный URL бэкенда
   в `app.js` → `CONFIG.leadEndpoint = 'https://<ваш-сервис>.onrender.com/api/lead'`.
